# 运行时与入口

## 应用从哪里开始

后端入口是 `app/main.py`。这里做了几件关键事情：

- 创建 FastAPI 应用
- 在 `lifespan` 中初始化数据库
- 注入请求日志、上传体积限制、HTTPS 跳转等中间件
- 挂载 API 路由、静态资源和文档入口

## 生命周期

启动时最重要的动作是 `init_db()`。这意味着数据库结构、索引、WAL 和相关初始化逻辑不是离线脚本先跑，而是应用启动阶段主动兜底。

## 中间件链路

当前实现至少包含这些横切能力：

- 请求日志与请求 ID
- 上传请求体积限制
- HTTPS 重定向
- 安全响应头注入
- 静态资源缓存控制

这类逻辑都收在入口文件中，所以排查跨接口问题时应优先看这里。

## 文档与公开入口

当前实现保留了 FastAPI 自带的：

- `/docs`
- `/redoc`
- `/openapi.json`

但在 secure runtime 下会关闭这些入口。

## 为什么这里值得优先看

因为这里同时决定了：

- 系统启动行为
- 安全边界
- 与 Nginx 的路径配合
- `/docs` 是否开放
