# LabStorageManager 表单组件重构计划

## 架构理念

采用**零件层 + 逻辑层**的混合模式：

| 层级 | 职责 | 示例 |
|------|------|------|
| **零件层** | 通用 UI 组件，无业务逻辑 | `FormField.tsx`, `FormModal.tsx` |
| **逻辑层** | 业务表单组件，包含专属验证 | `InventoryModal.tsx`, `UserModal.tsx` |

> 核心理念：业务验证逻辑内聚在各模块，避免在通用组件中引入分支判断。

## 零件层实现

### FormField.tsx

```tsx
interface FormFieldProps {
  label: string
  required?: boolean
  error?: { message?: string }
  description?: string
  suffix?: ReactNode
  colSpan?: string
  children: ReactNode
}

export function FormField({ label, required, error, description, suffix, colSpan, children }: FormFieldProps) {
  return (
    <div className={colSpan}>
      <Label>{label} {required && <span className="text-destructive">*</span>}</Label>
      <div className="relative">
        {children}
        {suffix && <span className="absolute right-3 top-1/2 -translate-y-1/2 text-muted-foreground">{suffix}</span>}
      </div>
      {description && !error && <p className="text-sm text-muted-foreground mt-1">{description}</p>}
      {error?.message && <p className="text-sm text-destructive mt-1">{error.message}</p>}
    </div>
  )
}
```

## 逻辑层实现

### InventoryModal.tsx（编辑/创建合一）

验证规则详见 `输入验证与状态管理.md` 或 `src/lib/schemas/inventory.ts`

```tsx
interface Props {
  open: boolean
  onOpenChange: (open: boolean) => void
  mode: 'create' | 'edit'
  initialData?: InventoryItem
  onSuccess?: () => void
}

export function InventoryModal({ open, onOpenChange, mode, initialData, onSuccess }: Props) {
  const isEdit = mode === 'edit'
  const schema = isEdit ? editInventorySchema : createInventorySchema  // 见 schemas/inventory.ts

  const { register, handleSubmit, reset, formState: { errors, isSubmitting } } = useForm({
    resolver: valibotResolver(schema),
    defaultValues: isEdit ? initialData : { quantity_bottles: 1, is_hazardous: false }
  })

  useEffect(() => { open && reset(isEdit ? initialData : { quantity_bottles: 1 }) }, [open, initialData])

  const mutation = useMutation({
    mutationFn: (data) => isEdit ? inventoryAPI.update(initialData!.id, data) : inventoryAPI.create(data),
    onSuccess: () => { toast.success(isEdit ? '更新成功' : '入库成功'); onSuccess?.(); onOpenChange(false) }
  })

  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogTitle>{isEdit ? '编辑库存' : '手动入库'}</DialogTitle>
      <form onSubmit={handleSubmit((data) => mutation.mutate(data))} className="space-y-4">
        <div className="grid grid-cols-1 sm:grid-cols-3 gap-4">
          <FormField label="物品名称" required error={errors.name} colSpan="col-span-2">
            <Input {...register('name')} />
          </FormField>

          <FormField label="CAS号" required error={errors.cas_number} readOnly={isEdit}>
            <Input {...register('cas_number')} className={isEdit ? 'bg-muted' : ''} />
          </FormField>

          {/* 其他字段... */}
        </div>

        <div className="flex justify-end gap-2 mt-6">
          <Button type="button" variant="morden" onClick={() => onOpenChange(false)}>取消</Button>
          <Button type="submit" disabled={isSubmitting}>{isSubmitting ? '提交中...' : (isEdit ? '保存' : '确认入库')}</Button>
        </div>
      </form>
    </Dialog>
  )
}
```

## 注意事项

1. **register vs Controller**：复杂组件（如 Checkbox）用 Controller
2. **数字类型**：设置 `valueAsNumber: true`
3. **密码强度**：在组件内用 `watch()` 计算，Valibot 只做底线拦截
4. **只读字段**：添加 `bg-muted` 样式
5. **性能优化**：用 `React.memo` 包裹 Modal 组件
