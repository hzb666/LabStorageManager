# 使用者指南总览

本组文档面向实验室日常使用者，说明主要页面、操作顺序和注意事项。内容按实际工作流程组织，避免技术实现细节。

## 系统能力范围

LabStorageManager 用于集中处理实验室采购、库存、借用、公告和账户管理。日常使用可分为三类：

- 订单：提交和跟进试剂订单、耗材订单。
- 库存：查询已入库物品，从实验步骤提取试剂并查库存，登记借用和归还。
- 个人工作区：查看待办、公告、登录设备和会话状态。

浏览器插件用于把外部采购平台购物车带入系统，导入页逐项确认后才会生成正式订单。智能机器人和 Agent 入口面向受控查询与确认后的操作，普通用户仍以网页操作为主。

## 适用角色

| 角色 | 主要职责 |
| --- | --- |
| 管理员 | 审批订单、维护用户、发布公告、查看操作日志 |
| 普通用户 | 下单、查库存、借还物品、处理个人待办 |
| 公用账户 | 公共终端查询、查看公告、代登记借用、补充库存基础信息 |

公用账户不能创建订单、手动新增普通库存、删除普通库存或使用导入功能。公用账户登记借用时，必须选择真实借用人。

## 核心对象

### 试剂订单

用于申请需要继续追踪的试剂。订单通过后，还需要处理到货和入库。正式入库后，物品进入库存页。

### 耗材订单

用于一次性耗材或不需要瓶级追踪的物品。耗材流程在确认收货或完成后结束，不会自动生成库存记录。

### 库存记录

表示实验室当前已经存在、可查询、可借用或可归还的物品。库存记录与订单记录分开保存，便于追溯采购和实际使用。

### 常用货架

用于集中管理共享、常备和高频使用的试剂。常用货架只展示被纳入该流程的物品，完整库存记录保留在库存管理页。

## 基本使用顺序

1. 先在库存管理或常用货架中确认是否已有现货。
2. 无现货或数量不足时，创建试剂订单或耗材订单。
3. 试剂到货后继续处理入库；耗材到货后确认收货或完成。
4. 入库后的试剂进入库存页，用于后续查询、借用和归还。
5. 个人待办优先回到仪表盘处理。

## 主要页面

| 页面 | 路由入口 | 主要用途 |
| --- | --- | --- |
| 仪表盘 | `/` | 查看个人待办、看板和全局统计 |
| 试剂订购 | `/reagents` | 提交和查看试剂订单 |
| 耗材订购 | `/consumables` | 提交和查看耗材订单 |
| 库存管理 | `/inventory` | 查库存、借用、归还、维护库存信息 |
| 常用货架 | `/common-shelf` | 查看和维护共享试剂 |
| 导入数据 | `/import` | 非公用账号批量补录库存 |
| 购物车导入 | `/cart-import` | 确认浏览器插件带入的购物车批次 |
| 个人账户 | `/devices` | 管理个人资料、密码和登录设备 |
| 用户管理 | `/admin/users` | 管理员维护账号 |
| 公告管理 | `/admin/announcements` | 管理员发布和维护公告 |
| 操作日志 | `/logs`、`/admin/logs` | 查看个人或管理员日志 |

## 入口速查

| 目标 | 建议入口 |
| --- | --- |
| 查看待办 | 仪表盘 |
| 申请采购试剂 | 库存或常用货架确认后，进入试剂订购 |
| 申请采购耗材 | 耗材订购 |
| 查找现有物品 | 库存管理 |
| 根据实验步骤查找试剂 | 库存管理页的实验步骤查库存 |
| 查看共享试剂 | 常用货架 |
| 处理归还 | 个人账号仪表盘的当前借用 |
| 完成待入库 | 非公用账号仪表盘的待入库 |
| 查看公告 | 顶部公告入口或铃铛 |
| 管理登录设备 | 个人账户 |
| 导入外部购物车 | 浏览器插件跳转到购物车导入页 |

## 使用要点

- 未登录访问业务页面时，系统会回到登录页。
- 管理员可见更多管理入口，普通用户和公用账户不可见。
- 公用账户不能创建订单、手动新增普通库存、删除普通库存或使用导入功能。
- 公用账户登记借用时必须选择真实借用人。
- 仪表盘内容会随账号类型变化。
- 公告可从铃铛查看，置顶公告也可能显示在页面顶部。
