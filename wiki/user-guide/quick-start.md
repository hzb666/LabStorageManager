# 快速上手

本页适合第一次登录系统的人，也可以作为新成员的简短培训说明。你不需要一次看完所有内容，只要先知道怎么登录、去哪看待办、怎么找到公告和主要入口就够了。

## 账号类型确认

系统里常见有三种账号：

- 管理员：负责审批、用户和公告管理。
- 普通用户：可以下单、查库存、借还物品和管理个人设备。
- 公用账户：适合公共电脑或共享场景，可查库存、看公告、登记借用，但不能自己下单。

登录后若未看到“创建订单”，应先确认当前是否为公用账户。

## 第一次登录怎么做

### 标准登录

第一次在这台设备上登录时，一般会看到标准登录页。你只需要输入：

- 用户名
- 密码

登录后会进入仪表盘，并把这台设备记到你的设备列表里，方便以后在个人账户页查看。

### 更快的登录方式

如果这台设备保存过同一个账号的登录信息，系统可能会直接显示最近登录用户。此时通常只要输入密码就能进入系统。

如果需要换人使用，记得先切换用户，再继续登录。这个功能适合个人设备，公共电脑上要格外注意。

### 常见登录提示

- 用户名或密码不对：重新核对输入内容。
- 登录状态已失效：说明原有会话已经过期或被清理。
- 服务未连接：一般不影响继续登录，但部分会话相关功能可能会变慢。

## 登录后的优先查看项

建议先花一点时间熟悉首页布局，再开始处理业务。

### 顶部区域

顶部常见有这几个入口：

- 公告横幅：显示置顶的重要通知。
- 公告铃铛：打开公告列表，并显示未读数量。
- 菜单和主题切换：在手机或窄屏设备上更常用。

铃铛存在未读数时，建议优先查看公告。采购规则、库存盘点、危险品提醒、节假日安排等通知，往往会影响后续操作。

### 再看左侧菜单

桌面端登录后，左侧一般会看到这些入口：

- 仪表盘
- 试剂订单
- 耗材订单
- 库存管理
- 常用货架
- 导入数据
- 个人账户

管理员还会额外看到：

- 用户管理
- 公告管理

### 从仪表盘开始

首页默认就是仪表盘。它更像个人工作台，主要用来查看还没处理完的事情。

## 先认识仪表盘

仪表盘会集中显示你的订单、借用和待入库事项。对新用户而言，这是最适合优先查看的页面。

普通用户和管理员通常会看到：

- 试剂订单
- 耗材订单
- 当前借用
- 待入库

公用账户看到的内容更少，通常只保留借用相关信息。

## 第一次浏览的推荐顺序

登录后可以先按这个顺序看一遍：

1. 打开公告列表，看看最近有没有重要通知。
2. 回到仪表盘，确认有没有借用或待入库事项。
3. 去库存里搜一项你熟悉的试剂。
4. 打开常用货架，了解实验室常备物品怎么找。
5. 再根据自己的工作去试剂订单或耗材订单页面。

这样可先了解“系统里已经有什么”，再进入下单流程。

## 先学会搜索

很多新手最常见的问题不是不会点按钮，而是没先确认系统里有没有现货。先查库存，通常能避免重复下单。

### 在库存里怎么搜

库存页常用的搜索条件有：

- 名称
- CAS 号
- 位置

找试剂时，优先用 CAS 号。只知道中文名也可以先搜名称，再点开详情确认是不是你要找的东西。

### 在常用货架里怎么搜

常用货架支持更多搜索条件，常见有：

- 名称
- 别名
- CAS 号
- 品牌
- 分类
- 位置

这个页面适合找共享试剂、常备试剂和高频使用物品。

### 仪表盘里的快速搜索

仪表盘的各个标签页通常也能搜索。比如：

- 试剂订单可以按名称、CAS 号、品牌和时间找。
- 耗材订单可以按名称、规格和时间找。
- 当前借用可以按名称和 CAS 号找。
- 待入库可以按名称和 CAS 号找。

若仅需查找当前个人事项，优先在仪表盘内搜索通常更快。

## 三个常见起步场景

### 场景一：申请试剂

建议这样做：

1. 先在库存管理和常用货架里搜名称或 CAS 号。
2. 确认没有现货或现货不够后，再去试剂订购。
3. 下单时尽量把名称、CAS 号、规格和用途写完整。
4. 提交后等待审批。
5. 物品到货后，在仪表盘里继续处理。
6. 需要补位置时，再进入待入库完成入库。

系统会在你下单时提醒是否已经有相关记录，方便你再确认一次。

### 场景二：申请耗材

建议这样做：

1. 先确认这件东西属于耗材，而不是需要继续跟踪的试剂。
2. 进入耗材订购。
3. 填好名称、规格、数量和说明。
4. 提交后等待管理员处理。
5. 物品到货后，在仪表盘或耗材订单里确认收货并结束流程。

一次性材料或低值易耗品通常走这个流程。

### 场景三：借用现有库存

建议这样做：

1. 去库存管理里按名称或 CAS 号搜索。
2. 看清规格、剩余量和位置。
3. 点击借用。
4. 实验结束后，到仪表盘的当前借用里归还。

使用公用账户借用时，应先选择真实借用人。

## 公告怎么用

公告有两个常见入口：

- 铃铛按钮：看完整公告列表和未读数。
- 顶部横幅：看置顶的重要公告。

可将铃铛理解为“公告列表”，将横幅理解为“当前最重要的提醒”。

建议养成这几个习惯：

- 存在未读数时，优先查看新公告。
- 可能影响工作流程的公告，尽量点开阅读全文。
- 横幅可暂时关闭，但后续仍可能再次出现。

## 尽早查看个人账户的原因

个人账户页不只是改头像和名字，还能管理登录设备。这里可以：

- 查看当前和历史登录设备
- 搜索设备名称或 IP
- 重命名设备
- 刷新会话
- 踢出其他设备

若需要在办公室、实验室终端和个人电脑之间切换，该页面会很有帮助。共享电脑使用结束后，也建议检查会话状态。

## 养成几个好习惯

### 1. 先查库存，再决定下不下单

库存和常用货架是最常看的入口，也最能帮你减少重复采购。

### 2. 试剂到货后别停在“已批准”

很多流程卡住，不是卡在审批，而是卡在到货后没有继续处理。

### 3. 借用后及时归还

当前借用是处理归还最集中的地方。及时归还有助于保持数据准确。

### 4. 共享电脑上记得切换用户

记住上次登录用户是方便个人设备的，但在公共电脑上要小心误用。

### 5. 看不到按钮时，先想想是不是账号类型不同

常见情况有：

- 没看到“创建订单”，通常是公用账户。
- 没看到“用户管理”“公告管理”，通常是普通用户。
- 仪表盘内容比较少，通常是账号类型决定的，不一定是页面出错。

## 常见概念

### 到货和入库不是一回事

到货只是说明东西送到了；入库才表示已经补好位置，并进入正式库存。

### 常用货架不是全部库存

常用货架更适合看共享、常备和高频使用的物品。完整库存还是要去库存管理看。

### 订单结束不等于进入库存

耗材订单通常到“完成”就结束，不会自动变成一条库存记录。

完成登录、查看公告和一次基础搜索后，即可开始日常使用。后续若主要处理待办，可继续阅读仪表盘；若主要处理采购或库存工作，再阅读订单页和库存页。
