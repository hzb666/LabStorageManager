# PRD.md - 实验室库存管理系统 (LIMS) vFinal

## 1. 项目愿景
构建一个轻量级、高性能的实验室试剂/耗材管理系统。核心解决重复录入问题，通过“订购单 -> 库存”的一键流转，实现对试剂生命周期的精细化管理。

## 2. 核心业务逻辑 (Business Logic)
* **双轨制管理**:
    * **耗材 (Consumables)**: 流程短。`申请` -> `审批` -> `采购` -> `到货确认` (流程结束，不进库存)。
    * **试剂 (Reagents)**: 流程长。`申请` -> `审批` -> `采购` -> `入库(生成唯一ID)` -> `借用/归还` -> `耗尽/报废`。
* **唯一性与防重**:
    * **CAS 号**: 作为核心索引。系统必须在后端强制清洗格式（去空格、大写）。在订购时，自动检索库存中相同 CAS 号的剩余总量并预警。
    * **一物一码**: 试剂入库时，若数量为 N，自动生成 N 条独立库存记录（如 `ETH-01`, `ETH-02`），便于追踪单瓶状态。

## 3. 用户角色与权限 (RBAC)
* **普通用户**:
    * 查看、查询、编辑、删除条目等常规操作。
    * 发起订购申请。
    * 借用/归还库存（仅限状态操作，不能物理删除）。
    * 执行“入库”操作。
    * 查看个人中心（Dashboard）。
* **管理员**:
    * 除普通用户的权限外，还有如下权限：
        * 审批/驳回申请。
        * 管理用户。
        * 导入/导出 Excel 数据。

## 4. 关键功能模块

### 4.1 个人中心 (Dashboard)
* **设计原则**: 替代手机扫码，作为用户操作的主阵地。
* **模块 A - 我的借用**: 卡片式展示当前用户名下所有“未归还”的试剂。点击“归还”弹出模态框。
* **模块 B - 申请进度**: 列表展示用户发起的订购单状态（待审批/已到货）。

### 4.2 订购与入库
* **图片处理**: 上传时后端强制压缩至 <100KB，生成缩略图存入文件系统，数据库仅存路径。
* **CAS 预警**: 输入 CAS 号后，前端自动调用接口查询库存，提示“库存中已有 X g，由某某购买”。

### 4.3 库存管理
* **归还逻辑**: 用户输入“剩余数值”（如 200）和单位（如 ml），系统自动计算剩余百分比（如 40%）。
    * 若剩余量 <= 0 或用户勾选“已用完”，状态变更为 `Consumed`。
    * **低量预警**: 剩余量 < 20% 时，UI 高亮显示。
* **位置管理**: 自由文本字段，允许输入“302冰箱第二层”。
* **危险品**: 增加 `is_hazardous` 标记，靠用户自觉管理。

### 4.4 数据迁移
* 支持 Excel 模板导入（含 CAS、名称、规格、别名、初始量、位置）。
