# 核心 API 与工作流

## 后端接口如何分层

接口层大致按业务对象拆分：

- 用户与会话
- 试剂订单
- 耗材订单
- 库存与常用货架
- 公告
- 日志与错误
- 购物车同步

## 试剂工作流

试剂接口分成两类文件：

- `reagent_orders.py`：列表与基础操作
- `reagent_orders_workflow.py`：审批、驳回、到货、入库等状态流转

这是理解试剂链路最重要的文件分工。

## 耗材工作流

耗材链路更短。它仍然有审批状态，但不会像试剂那样延伸到库存瓶级管理。

## 库存工作流

库存接口既承担列表、编辑、导入导出，也承担借用与归还。这里是系统最重的业务接口之一。

常见动作包括：

- 搜索库存
- 手动新增
- 导入模板和批量导入
- 借用与归还
- 查看借用历史

## 公告、日志和外围接口

- 公告负责系统通知
- 错误日志与用户日志用于追踪问题
- 购物车同步接口承担扩展导入能力
