## 8. 接口数据流

### 8.1 手动入库流程

```
前端表单 → InventoryFormSchema验证
  → POST /inventory/manual-add
  → 后端 normalize_cas() 清洗CAS号
  → parse_specification() 解析规格
  → compute_pinyin_fields() 计算拼音
  → 生成internal_code
  → 批量创建Inventory记录
```

### 8.2 编辑库存流程

```
前端表单 → 验证remaining_quantity
  → PUT /inventory/{id}
  → 后端验证remaining_quantity <= initial_quantity
  → 更新拼音字段（如果name/category/brand/alias变更）
  → 保存
```
