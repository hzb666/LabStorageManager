# 快速上手

这页适合第一次登录系统的新用户，也适合给新成员做一轮 10 到 15 分钟的上手培训。它不追求把所有功能讲全，而是帮你尽快完成第一轮真实使用：登录、看首页、读公告、找入口、避免常见误操作。

## 先确认账号类型

系统里常见的账号有三种：

- 管理员：能审批、看管理菜单、维护用户和公告。
- 普通用户：能创建订单、查库存、借还、管理自己的设备。
- 公用账户：更适合公共终端或共享场景，能查库存、看公告、登记借用，但不能创建订单。

如果你一登录就发现没有“创建订单”按钮，通常先别怀疑系统出错，先确认自己是不是用的公用账户。

## 第一次登录

### 普通登录

如果这是你第一次在当前设备上使用系统，通常会看到标准登录页。你需要输入：

- 用户名
- 密码

登录成功后，系统会进入首页仪表盘，并把当前设备记入你的会话列表，方便你之后在个人账户里查看。

### 再次登录时可能看到的锁屏模式

如果这台设备之前已经登录过同一个用户，系统可能不会再显示完整用户名输入框，而是进入一种更快的“锁屏式登录”：

- 页面会显示上次登录用户的头像、姓名或用户名。
- 你只需要输入密码即可重新进入系统。
- 如果现在要换人使用，记得点击“切换用户”回到普通登录模式。

这对个人电脑很方便，但在共享终端上尤其要注意切换用户，避免错用别人的登录身份。

### 登录时的几个常见提示

- 用户名或密码错误：重新核对输入内容即可。
- 登录状态已失效，请重新登录：说明之前的会话已经过期或被清理。
- Redis 服务未连接：这是系统给出的提醒，通常不影响你继续登录，但某些依赖会话的体验可能不如平时稳定。

## 登录后先看哪里

最推荐的顺序不是马上点菜单，而是先用 1 分钟把首页认熟。

### 第一步：先看顶部

页面顶部通常有三个你很快就会用到的区域：

- 左侧或中间：置顶公告横幅，桌面端会横向滚动显示重要通知。
- 右侧铃铛按钮：打开公告列表，并显示未读数量。
- 主题切换与菜单按钮：移动端尤其常用。

如果铃铛上有数字，建议先看公告，特别是采购规则、库存盘点、节假日安排、危险品管理等通知，往往会直接影响你后续操作。

### 第二步：看左侧菜单

桌面端登录后，左侧会出现主要导航菜单。高频入口通常包括：

- 仪表盘
- 试剂订单
- 耗材订单
- 库存列表
- 常用货架
- 导入数据
- 个人账户入口在侧边栏底部头像区域

如果你是管理员，还会额外看到：

- 用户管理
- 公告管理

### 第三步：从仪表盘开始，不要急着乱翻页

首页默认是仪表盘。它更像“个人工作台”，比起展示全站统计，更强调你现在手头有哪些事情待处理。

## 先认识仪表盘

首页默认就是仪表盘。这里会集中显示你的订单、借用和待入库事项，是最适合开始一天工作的页面。

普通用户和管理员通常会看到四类入口：

- 试剂订单
- 耗材订单
- 当前借用
- 待入库

公用账户的仪表盘会更简化，重点保留借用相关内容。

如果你想更系统地理解首页该怎么看、每张卡片分别做什么，建议继续阅读 [仪表盘](/user-guide/dashboard)。

## 推荐起步顺序

第一次登录后，建议按下面顺序跑一遍：

1. 打开公告列表，确认近期有没有重要通知。
2. 回到仪表盘，看有没有自己的当前借用或待入库。
3. 打开库存列表，尝试搜索一项你熟悉的试剂。
4. 再打开常用货架，看实验室常备物品通常长什么样。
5. 最后根据你的工作内容，再进入试剂订单或耗材订单。

这样做的好处是，你会先建立“系统里已经有什么”的直觉，而不是一上来就开始建单。

## 先学会搜索与筛选

很多新用户的问题不是不会点按钮，而是没有先查系统里是否已有现货。现实里最常见的浪费，就是实验室明明有库存，却又重复申购。

### 库存列表里的搜索思路

库存页的搜索框主要适合这些关键词：

- 名称
- CAS 号
- 位置

如果你要查试剂，优先推荐搜 CAS 号；如果你只记得中文名，也可以先搜名称，再展开详情确认。

### 常用货架适合怎么搜

常用货架的搜索字段比库存页更丰富，常见包括：

- 名称
- 别名
- CAS 号
- 品牌
- 分类
- 位置

它适合查共享试剂、常备试剂、大家经常重复使用的东西。很多时候，先查常用货架比先开订单更省事。

### 仪表盘列表也支持快速搜索

你在仪表盘各个标签页里也会看到搜索框。例如：

- 我的试剂订单可按名称、CAS 号、品牌、订购时间搜索。
- 我的耗材订单可按名称、规格、订购时间搜索。
- 我的借用记录可按名称、CAS 号搜索。
- 待入库可按名称、CAS 号搜索。

如果你只是想快速找到自己手里的某一条记录，先在仪表盘内搜，通常会比切去完整列表更快。

## 三个起步场景

### 场景一：我要申请一瓶试剂

建议这样做：

1. 先去库存管理和常用货架搜索名称或 CAS 号。
2. 确认没有现货或不够用，再进入“试剂订购”。
3. 创建订单时尽量把名称、CAS 号、规格、用途写清楚。
4. 提交后等待审批。
5. 批准后，如果物品已送达，再到仪表盘里确认到货。
6. 如果需要补位置，再到“待入库”完成入库。

补充一点：试剂建单时系统会根据 CAS 号做重复提醒，这正是为了帮你在提交前再核对一次系统里是否已有相关记录。

### 场景二：我要申请一批耗材

建议这样做：

1. 先确认它确实属于耗材，而不是需要库存追踪的试剂。
2. 进入“耗材订购”。
3. 填写名称、规格、数量、沟通信息等。
4. 提交后等待管理员审批。
5. 收到货后，在仪表盘或耗材订单页确认收货，让流程进入完成状态。

如果一个东西更像一次性材料、低值易耗品，通常优先走耗材流程。

### 场景三：我要借用现有库存

建议这样做：

1. 进入库存管理，按名称或 CAS 号搜索目标物品。
2. 确认规格、剩余量、位置。
3. 点击“借用”。
4. 实验完成后，在仪表盘“当前借用”中完成归还。

如果你使用的是公用账户，借用时系统会要求你选择真实借用人。这不是多此一举，而是为了让后续追踪更准确。

## 公告怎么用

系统里的公告入口有两个表现形式：

- 顶部铃铛按钮：用于查看完整公告列表和未读数。
- 顶部横幅：用于展示置顶且可见的重要公告，桌面端更明显。

你可以把铃铛理解成“公告收件箱”，把顶部横幅理解成“当前最重要的提醒”。

第一次使用时，建议养成这个习惯：

- 看到铃铛有未读数，先点进去看一眼。
- 对影响流程的公告，不要只看标题，尽量打开详情。
- 对暂时不想看的顶部横幅，可以先关闭，但它不是永久消失，更新后或过一段时间可能还会再次出现。

## 为什么早点看账户页

很多人以为“个人账户”只是改头像或改名字，其实它更重要的是设备会话管理。你可以在这里：

- 查看当前和历史登录设备
- 搜索设备名称或 IP
- 重命名设备，便于自己识别
- 刷新会话
- 一次性踢出所有其他设备

如果你在办公室电脑、实验室电脑、个人笔记本之间来回切换，这页非常有用。共享终端用完后，也建议及时检查会话状态。

## 这些习惯很重要

### 1. 先查库存，再下单

这是最重要的一条。系统已经把库存列表和常用货架做成了高频入口，就是为了降低重复采购。

### 2. 试剂到货后别停在“已批准”

很多流程不是卡在审批，而是卡在“物品到了，但没人继续点到货或补位置”。如果你申请的是试剂，到货后记得继续往后走。

### 3. 借了就及时归还

仪表盘里的“当前借用”就是帮你收尾的。不要等实验做完很久以后再补记，否则剩余量和责任人都会变模糊。

### 4. 共享电脑上一定注意切换用户

系统支持记住上次登录用户，这对个人设备是便利，对公用设备则是风险。每次交接人之前，最好确认是否需要切换用户或退出登录。

### 5. 看不到按钮时先判断是不是角色差异

比如：

- 没有“创建订单”，可能是公用账户。
- 没有“用户管理”“公告管理”，可能不是管理员。
- 仪表盘卡片变少，可能是角色不同，而不是页面坏了。

## 新手常见误会

### “到货”和“入库”不是一回事

试剂到货只是说明东西到了；入库还意味着它已经补充了位置、真正进入可管理库存。

### “常用货架”不等于“全部库存”

常用货架更像共享视图，适合看高频、公用、常备试剂；完整库存还是要去库存列表查。

### “订单结束”不一定等于“进入库存”

耗材订单通常以采购完成为主，不会自动变成你在库存列表里管理的一条库存记录。
