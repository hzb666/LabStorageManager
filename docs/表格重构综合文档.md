### 3.2 粘性表头 (Sticky Header)

**实现方式**：CSS sticky 定位

```tsx
<div
  className={cn(
    "sticky w-full bg-secondary border-b-2 border-border rounded-t-md z-30",
    stickyHeader && "top-0"
  )}
  style={stickyHeader ? { top: `${stickyTopOffset}px` } : undefined}
>
```

**配置项**：

| Prop            | 类型    | 默认值 | 说明                             |
| --------------- | ------- | ------ | -------------------------------- |
| stickyHeader    | boolean | true   | 是否启用粘性表头                 |
| stickyTopOffset | number  | 64     | 距离页面顶部的偏移量（页眉高度） |

### 3.3 动态列宽计算

**最右侧是固定的不能拖动
**

**逻辑**：

```
tableWidth = max(columnTotalWidth, containerWidth)
```

- 如果列总宽 >= 容器宽 → 使用列总宽（产生横向滚动条）
- 如果列总宽 < 容器宽 → 使用容器宽（铺满整个视图，无横向溢出）

**拖动限制**：

```tsx
if (startTotalWidth <= containerWidth) {
  // 限制最大拖动宽度不超过容器宽
}
```

## 七、附录：TanStack 官方最佳实践

### 7.1 虚拟滚动关键点（来自官方文档）

1. **scrollMargin**：当有页眉或其他内容在虚拟列表之前时，必须设置 scrollMargin
2. **estimateSize**：提供准确的估算值可减少调整次数
3. **overscan**：适当增加 overscan 可防止快速滚动时出现白屏

### 7.2 列宽拖拽关键点（来自官方文档）

1. **columnResizeMode**：设为 'onChange' 可获得实时反馈
2. **getResizeHandler()**：内置处理鼠标/触摸事件
3. **双击重置**：调用 `header.column.resetSize()`
