# 使用者指南总览

本组文档面向实验室日常使用者，重点说明系统里常见的页面、入口和操作顺序。这里不讲技术细节，只帮助你判断“该去哪里做、做完会看到什么、哪些地方要特别注意”。

## 这个系统能做什么

LabStorageManager 主要用于处理实验室里的采购、库存、借用、公告和账户管理。你可以把它理解成一个把日常事务集中到一起的工作台。

从使用者角度看，系统大致分成三类内容：

- 订单：用来提交采购申请，包含试剂订单和耗材订单。
- 库存：用来查看已经在实验室里的物品，并进行借用和归还。
- 个人工作区：用来查看待处理事项、公告和个人账户信息。

## 适合谁使用

系统主要有三类账号：

- 管理员：负责审批、用户管理、公告管理和部分维护工作。
- 普通用户：负责下单、查库存、借还物品和处理个人事项。
- 公用账户：适合公共终端或共享查询场景，可查库存、看公告、登记借用，但不能自己下单。

如果你是第一次使用，建议先看 [快速上手](/user-guide/quick-start)；如果你想知道不同账号能看到什么，再看 [角色与导航](/user-guide/roles-and-navigation)。

## 常见工作

系统最常见的日常操作包括：

- 提交试剂采购申请，并继续处理审批、到货和入库。
- 提交耗材采购申请，并在收货后结束流程。
- 在库存里按名称、CAS 号或位置查找物品。
- 在库存中借用物品，并在实验结束后归还。
- 在常用货架中查看共享试剂或常备物品。
- 在仪表盘里查看自己的待办事项。
- 在公告入口查看通知，重要公告会显示在顶部。
- 在个人账户里查看登录设备和会话状态。

## 你需要认识的三个对象

### 试剂订单

试剂订单用于申请需要继续追踪的试剂。通常你会填写名称、CAS 号、规格、品牌等信息。订单通过后，还要继续处理到货和入库。

### 耗材订单

耗材订单用于一次性耗材或不需要继续追踪库存的物品。重点是把采购流程走完，而不是把它变成一条库存记录。

### 库存记录

库存记录表示物品已经在系统里，可以被查找、借用、归还和查看详情。你可以把它理解成“实验室现在真的有哪些东西”。

## 它们之间的关系

通常会按下面的顺序处理：

1. 先确认实验室里有没有现货。
2. 没有现货，再创建试剂订单或耗材订单。
3. 试剂到货后，继续做入库处理。
4. 耗材到货后，确认收货或完成即可。
5. 已正式入库的物品会进入库存页面，供后续查询和借还。

这也是为什么订单页和库存页是分开的。

## 主要页面

| 页面 | 路由入口 | 主要用途 |
| --- | --- | --- |
| 仪表盘 | `/` | 查看待处理事项 |

| 耗材订购 | `/consumables` | 提交和查看耗材订单 |
| 库存管理 | `/inventory` | 查库存、借用、归还和入库 |

## 快速判断该去哪里

| 你想做什么 | 建议去哪里 |
| --- | --- |
| 看今天还有哪些待办 | 仪表盘 |
| 申请采购试剂 | 先查库存或常用货架，再去试剂订购 |
| 申请采购耗材 | 耗材订购 |
| 查找现有试剂 | 库存管理 |
| 看共享试剂 | 常用货架 |
| 处理归还 | 仪表盘里的当前借用 |
| 补录位置完成入库 | 仪表盘里的待入库 |
| 看通知 | 顶部公告按钮 |
| 处理设备会话 | 个人账户 |

## 使用时记住这几条

- 没登录时，进入业务页面会被带回登录页。
- 管理员会看到额外的管理入口，普通用户看不到。
- 公用账户不能创建订单。
- 公用账户借用时，要选择真实借用人。
- 仪表盘会根据账号类型显示不同内容。
- 公告既可以从铃铛里看，也可能直接显示在顶部。

## 最后建议

刚开始用的时候，先养成这个顺序会比较顺：

- 先查有没有现货。
- 再决定要不要下单。
- 到货后继续完成后续处理。
- 借用后及时归还。
- 不确定时，先回仪表盘看待办。
