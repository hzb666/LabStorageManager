# 使用者指南总览

这组文档写给实验室库存管理系统的日常使用者。你不需要了解系统的技术细节，只需要知道自己现在想做什么，就可以沿着对应页面完成操作。文档重点帮助你建立一个稳定的使用路径：去哪个页面、看到哪些状态、下一步该怎么做。

## 系统是什么

LabStorageManager 不是单纯的库存台账，而是一套把实验室日常几条主线串起来的工作平台。它覆盖了从申购、审批、到货、入库，到库存查询、借用、归还、公告提醒、设备会话管理的一整套流程。和用 Excel、聊天记录、纸质登记分散处理相比，这套系统更适合多人协作，也更适合事后追踪。

如果你是第一次接触这套系统，可以先把它理解成三层：

- 订单层：我要申请购买什么。
- 库存层：什么东西已经真的在实验室里。
- 个人工作层：我今天有哪些待处理事项，比如到货确认、待入库、当前借用、未读公告。

## 适合谁用

它主要服务三类使用者：

- 管理员：负责审批、管理用户、维护公告、处理部分导入和追踪工作。
- 普通用户：负责日常申购、查库存、借还物品、查看公告、管理自己的设备会话。
- 公用账户使用者：适合公共终端、值班电脑或共享查询场景，重点用于查库存、看公告、登记借用，不适合创建订单。

如果你只是偶尔查一次库存，可以先看 [快速上手](/user-guide/quick-start)。  
如果你要弄清楚每个菜单和角色差异，建议接着读 [角色与导航](/user-guide/roles-and-navigation)。

## 系统能帮你做什么

从真实页面来看，当前系统已经能稳定覆盖这些高频场景：

- 提交试剂订单，按状态跟踪待审批、已批准、已到货、已入库。
- 提交耗材订单，跟踪审批进度，并在收货后确认完成。
- 在库存列表中按名称、CAS 号、位置等条件搜索现有库存。
- 从库存中发起借用，并在实验后按使用量或剩余量归还。
- 在常用货架里集中查找共享或常备试剂，减少重复申购。
- 在仪表盘集中查看“我的试剂订单”“我的耗材订单”“当前借用”“待入库”。
- 通过顶部公告入口查看未读公告，并在桌面端看到置顶公告横幅。
- 在个人账户页面查看当前登录设备、刷新会话、重命名设备、踢出其他设备。

## 三个核心对象

很多页面看起来不同，但大多数工作都围绕三个核心对象展开。

### 1. 试剂订单

试剂订单用于申请购买需要更强追踪能力的物品。它通常会带上 CAS 号、规格、品牌、用途等信息。试剂订单会经过审批；审批通过后，可以在仪表盘中继续确认到货，再进入入库流程。

你可以把它理解成“我要买一瓶试剂，而且希望后续能一路追踪到到货和入库”。

### 2. 耗材订单

耗材订单更适合一次性耗材、低值易耗品或不需要瓶级库存追踪的物品。它也会经历审批，但后续更像采购闭环，重点是“已批准”和“已完成”，而不是像试剂那样继续走入库定位。

你可以把它理解成“我要采购一批耗材，并确认这次采购有没有收齐”。

### 3. 库存记录

库存记录表示物品已经进入系统库存，可以被搜索、借用、归还和查看详情。库存会记录名称、CAS 号、规格、剩余量、位置、危险标记、借用状态等。

对使用者来说，库存记录才是“实验室里现在真的有什么”的答案。

## 三者关系

如果把业务过程串起来，通常是这样：

1. 先判断实验室里有没有现货。
2. 没有现货，再创建试剂订单或耗材订单。
3. 试剂订单批准后，可继续确认到货，再补位置完成入库。
4. 耗材订单批准后，通常以确认收货作为流程结束。
5. 已入库的物品会进入库存视图，供后续查询、借用、归还。

这也是为什么系统里“订单页面”和“库存页面”同时存在，而且不能相互替代。

## 核心能力一览

从使用者能直接感知到的角度，可以把核心能力归纳成下面几组：

- 采购与审批：试剂、耗材分开建单，状态清晰，管理员可审批。
- 到货与入库：试剂支持确认到货，也支持直接一键入库或稍后补位置。
- 库存查询与借还：库存列表和仪表盘都能帮助你找到现有物品与未归还项目。
- 共享试剂管理：常用货架把公用或高频使用试剂集中展示。
- 站内通知：公告按钮会显示未读数，置顶公告会在顶部横向展示。
- 账户安全：登录状态失效会被带回登录页，个人账户可管理设备会话。

## 常见页面

系统的业务入口主要集中在这些路由和菜单中：

| 页面 | 路由入口 | 你通常会在这里做什么 |
| --- | --- | --- |
| 仪表盘 | `/` | 看自己的订单、借用、待入库，快速回到手头任务 |
| 试剂订购 | `/reagents` | 创建、查看、搜索试剂订单；管理员可审批和导出 |
| 耗材订购 | `/consumables` | 创建、查看、搜索耗材订单；管理员可审批和导出 |
| 库存管理 | `/inventory` | 搜索库存、查看位置、借用、编辑、手动入库 |
| 常用货架 | `/common-shelf` | 查找共享试剂、常备试剂，减少重复申购 |
| 导入数据 | `/import` | 使用模板进行批量导入或补录 |
| 个人账户 | `/devices` | 管理个人信息、设备会话、踢出其他设备 |
| 用户管理 | `/admin/users` | 管理员维护账号、启停用户、查看用户信息 |
| 公告管理 | `/admin/announcements` | 管理员发布、编辑、置顶、隐藏公告 |
| 用户操作日志 | `/admin/logs` | 管理员查看关键操作记录 |

## 使用时记住这些

- 未登录访问业务页面时，系统会把你带回登录页。
- 管理员页面有单独入口，普通用户不会看到“用户管理”“公告管理”“用户操作日志”菜单。
- 公用账户不能创建订单，所以在试剂订购和耗材订购页不会出现“创建订单”按钮。
- 公用账户可以在库存页借用，但必须选择真实借用人，不能把公用账户当作实际使用者。
- 仪表盘会按角色裁剪内容，公用账户只保留“当前借用”这一类个人工作视图。
- 公告不仅能在铃铛按钮里查看，置顶公告还可能以顶部横幅形式出现。

## 建议先形成的心智模型

对新用户来说，不必一开始就把所有按钮都记住。更实用的做法是记住下面这条线：

- 先查有没有。
- 再决定要不要买。
- 到货后别忘了继续处理。
- 借出去的东西要归还。
- 看不清时回到仪表盘。

只要这个顺序清楚，大部分页面都会越用越顺。
