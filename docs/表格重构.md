# 📚 Frontend Advanced Skills: TanStack-Driven Headless Table Architecture (V2 进阶版)

## 🎯 核心目标
在构建海量数据（万级别）的实验室库存管理系统时，采用 **TanStack Headless UI** 架构，彻底剥离原生 HTML 表格的限制。实现状态全托管、DOM 虚拟化、平滑的动画交互、动态列宽拖拽（含持久化）以及服务端分页与排序。

## 🛠 技术栈基准
* **核心状态与逻辑**: `@tanstack/react-table` (Headless Table API)
* **性能与滚动**: `@tanstack/react-virtual` (虚拟化长列表)
* **动画引擎**: `framer-motion` (处理行展开/收起的丝滑过渡)
* **样式引擎**: Tailwind CSS (配合 `cn` 动态类名) + Lucide Icons

---

## 🚨 Agent 开发核心军规 (Core Rules for Agent)

### 1. 彻底摒弃原生 Table，拥抱 Headless UI
* **禁用原生标签**：绝对禁止使用 `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<td>`。
* **Flex/Grid 重构**：统一使用 `<div>` 配合 `flex`。表头和数据行必须使用相同的宽度分配规则（通过 `style={{ width: cell.column.getSize() }}` 动态绑定），以保证上下严格对齐。

### 2. 状态全托管 (State Management)
* **禁止私有状态**：行组件内部禁止使用 `useState` 记录展开（`isExpanded`）状态。必须通过 `row.getToggleExpandedHandler()` 触发内置逻辑。
* **列宽状态持久化**：列宽的调整（Resizing）状态需保存在 `localStorage` 中，并在初始化时注入给 Table 实例。支持双击 Resizer 恢复默认列宽。

### 3. TanStack Virtual 绝对定位与动态测算
* **动态高度测算 (最高优先级)**：必须将 `virtualizer.measureElement` 方法绑定到每一个虚拟行最外层容器的 `ref` 上。这是解决 Framer Motion 动画改变行高时与虚拟滚动冲突的唯一解法。
* **横向防溢出**：主容器必须设置 `overflow-auto`，内部容器设置 `min-w-full` 并绑定 `style={{ width: table.getTotalSize() }}`，确保列宽总和小于视窗时铺满，大于视窗时出横向滚动条。

### 4. 服务端排序 (Server-Side Sorting)
* 万级数据量必须弃用前端排序。
* Table 实例必须配置 `manualSorting: true`。
* 严禁在 `useReactTable` 中引入 `getSortedRowModel()`。
* 必须监听 `sorting` 状态变化，将其转化为 API 参数（如 `sort_field` 和 `sort_order`）发送给后端，并在排序条件变更时重置页码为第一页。

## 📦 核心组件代码：`DataTable.tsx`

```tsx
import React, { useRef } from 'react'
import { flexRender, Table } from '@tanstack/react-table'
import { useVirtualizer } from '@tanstack/react-virtual'
import { motion, AnimatePresence } from 'framer-motion'
import { ArrowDown, ArrowUp, ArrowUpDown } from 'lucide-react'
import { cn, formatDate } from '@/lib/utils'

interface DataTableProps<TData> {
  table: Table<TData>
}

// --- 单行组件：全动态测算与 Headless 布局 ---
function HeadlessVirtualRow({ row, virtualRow, measureRef }: any) {
  const isExpanded = row.getIsExpanded()
  const original = row.original

  return (
    <div
      ref={measureRef} // 【关键】：TanStack 实时测量 DOM 高度
      data-index={virtualRow.index}
      className="absolute top-0 left-0 w-full"
      style={{ transform: `translateY(${virtualRow.start}px)` }} // 【关键】：虚拟定位
    >
      {/* 基础行：Flex 布局替代 <tr> */}
      <div
        className={cn(
          "flex w-full border-b border-border cursor-pointer transition-colors bg-background items-center",
          isExpanded ? "bg-muted/30" : "hover:bg-muted/50"
        )}
        onClick={row.getToggleExpandedHandler()} // 【关键】：状态交由 TanStack
      >
        {row.getVisibleCells().map((cell: any) => (
          <div
            key={cell.id}
            className="p-3 text-base truncate flex-shrink-0"
            style={{ width: cell.column.getSize() }} // 【关键】：响应拖拽的动态列宽
          >
            {flexRender(cell.column.columnDef.cell, cell.getContext())}
          </div>
        ))}
      </div>

      {/* 展开区域：条件渲染 + 动画引擎 */}
      <AnimatePresence>
        {isExpanded && (
          <motion.div
            initial={{ height: 0, opacity: 0 }}
            animate={{ height: "auto", opacity: 1 }}
            exit={{ height: 0, opacity: 0 }}
            transition={{ duration: 0.3, ease: "easeInOut" }}
            className="overflow-hidden bg-muted/20 border-b border-border"
          >
            <div className="p-4 grid grid-cols-2 md:grid-cols-3 gap-x-6 gap-y-2 text-base">
              <div><span className="font-medium">英文名称：</span>{original.english_name || '-'}</div>
              <div><span className="font-medium">别名：</span>{original.alias || '-'}</div>
              <div><span className="font-medium">入库时间：</span>{formatDate(original.created_at)}</div>
              <div><span className="font-medium">入库用户：</span>{original.created_by_name || '-'}</div>
              <div><span className="font-medium">备注：</span>{original.notes || '-'}</div>
            </div>
          </motion.div>
        )}
      </AnimatePresence>
    </div>
  )
}

// --- 列表主容器：全权接管滚动、渲染与列宽控制 ---
export function DataTable<TData>({ table }: DataTableProps<TData>) {
  const scrollContainerRef = useRef<HTMLDivElement>(null)
  const { rows } = table.getRowModel()

  const rowVirtualizer = useVirtualizer({
    count: rows.length,
    getScrollElement: () => scrollContainerRef.current,
    estimateSize: () => 53, // 闭合状态的基础高度
    overscan: 5,
  })

  return (
    <div
      ref={scrollContainerRef}
      className="h-[600px] w-full overflow-auto rounded-md bg-background border border-border shadow-sm"
    >
      <div 
        className="flex flex-col text-left relative min-w-full" 
        style={{ width: table.getTotalSize() }} // 【关键】：高度由内部行撑开，宽度横向自适应
      >
        {/* Headless 表头：Sticky 定位与拖拽热区 */}
        <div className="sticky top-0 bg-secondary z-20 w-full flex border-b-2 border-border">
          {table.getHeaderGroups().map((headerGroup) => (
            <React.Fragment key={headerGroup.id}>
              {headerGroup.headers.map((header) => {
                const canSort = header.column.getCanSort()
                const isSorted = header.column.getIsSorted()

                return (
                  <div
                    key={header.id}
                    className="relative p-3 font-semibold text-foreground flex items-center flex-shrink-0 group select-none hover:bg-muted/10 transition-colors"
                    style={{ width: header.getSize() }}
                  >
                    {/* 表头内容区（支持点击排序） */}
                    <div 
                      className={cn("flex items-center gap-1.5 w-full", canSort && "cursor-pointer")}
                      onClick={header.column.getToggleSortingHandler()}
                    >
                      <span className="truncate">
                        {header.isPlaceholder ? null : flexRender(header.column.columnDef.header, header.getContext())}
                      </span>
                      {canSort && (
                        <span className="w-4 h-4 flex-shrink-0 flex items-center justify-center text-muted-foreground">
                          {isSorted === 'asc' ? <ArrowUp className="w-3.5 h-3.5" /> : 
                           isSorted === 'desc' ? <ArrowDown className="w-3.5 h-3.5" /> : 
                           <ArrowUpDown className="w-3.5 h-3.5 opacity-0 group-hover:opacity-50 transition-opacity" />}
                        </span>
                      )}
                    </div>
                    
                    {/* 列宽拖拽把手：双击恢复默认值 */}
                    {header.column.getCanResize() && (
                      <div
                        onMouseDown={header.getResizeHandler()}
                        onTouchStart={header.getResizeHandler()}
                        onDoubleClick={() => header.column.resetSize()} // 双击重置
                        className={cn(
                          "absolute right-0 top-0 h-full w-2 cursor-col-resize z-10 touch-none transition-all opacity-0 group-hover:opacity-100",
                          header.column.getIsResizing() ? "bg-primary opacity-100 w-2" : "hover:bg-primary/50"
                        )}
                      />
                    )}
                  </div>
                )
              })}
            </React.Fragment>
          ))}
        </div>

        {/* 虚拟滚动内容轨道 */}
        <div
          className="relative w-full"
          style={{ height: `${rowVirtualizer.getTotalSize()}px` }}
        >
          {rowVirtualizer.getVirtualItems().map((virtualRow) => {
            const row = rows[virtualRow.index]
            return (
              <HeadlessVirtualRow
                key={row.id}
                row={row}
                virtualRow={virtualRow}
                measureRef={rowVirtualizer.measureElement}
              />
            )
          })}
        </div>
      </div>
    </div>
  )
}
```
