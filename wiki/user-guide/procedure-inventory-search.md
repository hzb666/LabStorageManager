# 实验步骤查库存

实验步骤查库存用于从实验记录中识别试剂名称，解析 CAS 号，并在库存页集中查看可用情况。该功能提供辅助检索结果，原始实验步骤和实际库存记录仍是核对依据。

## 使用条件

- 管理员和普通用户可以使用。
- 公用账户不显示该入口。
- 后端需要启用并配置 OpenAI 兼容 LLM 接口。
- 单次输入最多 5000 个字符。

## 操作流程

1. 打开库存管理页，点击 **实验步骤查库存**。
2. 粘贴实验步骤并提交解析。
3. 系统提取全部物料，对身份明确的物料用原名、规范查询名及可靠中文名匹配本地名称、别名、库存和结构缓存；没有本地匹配时再通过 PubChem 解析 CAS 候选。取得 CAS 后，命中公用常用列表的跳过普通库存，其余 CAS 进入库存查询。
4. 解析完成后进入库存页，CAS 查询条件会以 `&&` 连接。
5. 在解析面板中核对原文高亮、CAS 候选和库存命中情况。
6. 点击 **导出实验报告**，打开包含格式化原文、完整匹配库存和投料记录表的 A4 报告。可填写实验信息、当量及投料量后打印或保存为 PDF。

解析过程分为实验步骤识别、PubChem 解析和库存查询三个阶段。打开结果页后，供该页面读取的结果缓存有效期为 10 分钟，并限定在当前登录用户和当前浏览器会话内。

查询期间可以关闭弹窗继续操作，再次点击入口会恢复原输入和加载进度，不重复发起请求。弹窗关闭后，查询完成只显示提示，不自动跳转；再次点击 **实验步骤查库存** 会打开已完成的结果。未查看的结果保存在页面内存中，切换系统内路由不清除，刷新页面、退出登录或切换账号后清除。弹窗仍打开时，完成后直接进入结果页。后台查询失败会显示错误 toast，原输入会保留供重新打开后重试。

入口右上角的小蓝点表示正在查询，小绿点表示结果已完成、点击可查看；查看结果或查询失败后提示点消失。

试剂提取使用中文提示词，同一次 LLM 请求中每个物料只返回原名、中文名、PubChem 查询名、混合物标记、当量共五项。无明确当量时该项为 `null`；有当量时才包含数值、原文依据和置信度。后端从查询名是否为空派生检索目标标记，不再让模型重复输出，也不输出未使用的一般置信度和重复原文。LLM 不判断是否公用常用，不接收固定词表或整张数据库名称名单，也不在模型返回后用正则补加物料。后端取得 CAS 后按 CAS 主数据表核对公用常用身份，与公用常用订单采用同一数据来源，不依赖英文名称是否相同。

常用物料也先解析 CAS，保留查询名和解析结果；多个候选 CAS 分别判断，只有命中公用常用列表的候选跳过普通库存。身份未知的编号物料保留原编号。非单一化合物的材料由 LLM 根据实验语境和化学常识确定标准主体成分或主溶质，保留原物料名称及配制限定词；不因配方或浓度未写明就拒绝常规成分检索，置信度表示候选的不确定性，确实无法确定目标时才留空。结果中的“成分 CAS”属于检索目标，不表示整份混合物就是纯成分。逐个列出的混合溶剂分别提取，不把每种溶剂当作混合物。未知泛指、编号和粗产物保留；明确指回已有物料的普通称呼不重复列项。明确缩写和同义词由 LLM 提供规范查询名，PubChem 继续按名称及同义词解析。没有可靠中文名时保留原文，不使用前端固定翻译表。后端继续校验输出格式、数值、当量置信度和原文证据。CAS、库存、分子量与投料计算由程序处理，不由 LLM 输出。

## 结果状态

| 状态 | 含义 | 处理方式 |
| --- | --- | --- |
| 已识别 CAS | 试剂名称已解析出 CAS | 核对候选 CAS 和库存命中项 |
| 库存未命中 | CAS 已识别，库存中未找到对应记录 | 核对 CAS 后决定采购或补录 |
| 未识别 CAS | 试剂名称未得到可用 CAS | 参考候选信息并手动搜索名称 |
| 常用不查 | CAS 已命中公用常用列表 | 跳过普通库存，按常用货架和实际物料核对 |
| 通类不查 | 泛指、未知编号或无法唯一确定身份的混合物 | 保留原文，补充具体化合物身份后重新查询 |

当一个名称对应多个 CAS 时，面板会展示候选列表。库存查询会带入有限数量的候选 CAS，使用者需要结合实验上下文确认目标化合物。

## 打印实验报告

- 库存表初始包含本次 CAS 对应的全部库存记录，不受当前表格分页或后续筛选影响，按名称、CAS、位置、品牌和“剩余/规格”排列，名称加粗；借用、暂存及未找到库存的情况会明确标出。
- 同一物料有多个候选 CAS 时，任一候选命中库存就只展示命中的记录，隐藏其余空候选；全部未命中时只按主 CAS 保留一行“未找到库存”。多个候选均有库存时保留全部命中瓶记录；重叠候选和别名不会造成同一 CAS 的重复空行。
- 报告按库存核对、实验步骤、投料记录排列。名称过长时单行省略，悬浮可查看完整名称；标题、实验信息、投料名称、实验步骤和参考文献均可编辑，统一在离开编辑区域后重新分页，不打断中文输入。步骤下方的“参考文献：”使用普通字号加粗，后面可直接粘贴文献内容。
- 两张表均可将鼠标移到名称单元格，点击小红圆叉删除当前行；左侧的查找图标可在新标签页打开该 CAS 的 ChemicalBook 页面，没有唯一确定 CAS 时不可查找。操作按钮悬浮显示，不占列宽；键盘聚焦操作按钮时也会显示，触屏设备直接显示。点击操作后会隐藏，重新移入单元格或触屏再次点击名称可恢复；编辑名称期间保持隐藏。删除只作用于当前报告，两张表互不联动，不会修改系统库存；删除投料基准行仍保留已确定的基准和其余投料数据。打印时操作按钮自动隐藏。
- 报告预览和打印均按 A4 分页，跨页表格重复表头并标明页码。字体复用系统当前已加载的字体注册和浏览器缓存，不再为报告单独加载整份中文字体。
- 实验步骤与参考文献共用文字分页，较长文献会自动续页；重复打印和重新分页不会把文献并入步骤或重复内容。
- 顶部可缩小、放大或适应宽度，预览范围为 25%–200%；点击百分比恢复 100%。手机打开时自动适应宽度，适应模式会随窗口宽度调整。缩放不改变填写内容、A4 分页和打印尺寸。
- 缩放控件居中，打印/保存 PDF 使用系统强调按钮，其余使用常规按钮。“重置 PDF”会恢复刚导出时的内容，清除当前报告内全部文字修改、填写和删行，并恢复初始缩放；无需重新联网生成。
- 投料表保留解析出的试剂，包括常用及未识别物料；同一 CAS 的重复名称合并为一行。名称使用中文，可直接编辑补充；待确认提示只出现在分子量栏。
- 泛指物料及仅有编号的化合物也保留独立投料行，例如底物、化合物 3、中间体 A、3a；编号和后缀按原文保留，不会合并不同编号。无法确定具体身份时不查询库存或臆测分子量，分子量显示待确认，明确标注的当量仍会预填。
- 无明确当量的常用试剂、溶剂和通类物料放在投料表末尾；有明确当量的常用物料与普通试剂一起按原文顺序排列，正常显示分子量和当量，但仍不查询库存。LLM 在同一次试剂解析中结合上下文识别明确标注的 `eq`、`equiv.` 或中文当量，并返回原文依据；高置信度且依据能在原文核对的结果会自动填入。范围、约数、关联不明和冲突标注留空，仍可手动修改。当量不通过前端固定规则提取，也不根据原文质量或 mmol 推算；旧的查询结果需重新解析后才会取得 LLM 当量。
- 报告采用紧凑排版，省略说明文字和装饰，尽量在一页 A4 内展示；内容较多时继续自动分页，不截断实验步骤或库存表。
- 填写质量或 mmol 可建立 1 当量基准，有效密度下填写体积也可反算；其他试剂填写当量后会联动计算计划投料和 mmol，也可手动设置基准 mmol。质量支持 mg、g、μg、kg，体积支持 μL、mL、L。修改基准会更新各行计划投料，实际投料独立填写。体积缺少密度时不自动换算，不自动套用原文的量。
- 逐字输入单位、科学计数法或先填体积后补密度时，保留已填写的当量；无法换算时暂时清空计算量，输入完整后恢复联动。清空数量不会连带删除当量，实际投料记录也独立保留。
- 分子数据优先取本地已确认的化学品数据，缺少时一次获取 PubChem 的分子式和分子量；本地分子式仍可计算分子量，支持括号和结晶水，人工确认的结构始终优先。
- 报告补充分子数据的外部查询共享约 5 秒等待预算，不自动重试；查询成功的分子数据在当前后端进程缓存 24 小时，不可用结果缓存 60 秒，库存每次重新读取。超时仍可打印已取得的数据，其余显示待确认。
- CAS 在库存核对表中展示，投料记录保留试剂名称、分子量、密度、当量和投料量。
- 物料有多个候选 CAS 时，库存核对表在显示的 CAS 后标注“等”；只有一个确定 CAS 时不加标记。
- 分子量可手动填写或修改，修改后单元格右上角显示小蓝点；恢复原值时蓝点消失。修改分子量保持已确定的物质的量与反应规模不变，重新换算计划投料；重置 PDF 会恢复初始分子量并清除标记。
- 可自行填写密度（g/mL），密度保留输入精度，其余数值显示两位小数。未填密度时按质量换算；填入有效密度后按体积显示，低于 10000 μL 用 μL，达到 10000 μL 用 mL。
- 修改或清除密度保持已确定的计划投料物质的量不变，只换算体积或恢复质量；实际投料是独立记录，不影响基准与当量。填写密度后，无单位的投料量按 μL 处理，也可明确填写 mL、mg 或 g。
- 密度应取对应试剂产品的数据并核对温度、纯度，溶液还需要浓度，不能仅凭密度按纯试剂分子量换算。报告不自动选取外部密度值，不增加导出的联网等待。
- 常用物料也会补充分子量，复用已解析的 CAS；导出报告时同样跳过这些 CAS 的普通库存查询。
- 溶液和混合物保留自己的名称与独立投料行，不与其纯成分合并，也不将成分分子量直接当作整份混合物的分子量计算投料。
- 同一查询名的多个写法会合并别名，再一起匹配本地数据；同一 CAS 的分子量在一次报告生成中只计算一次。
- 多个候选 CAS 的分子量全部存在且一致时，显示共同分子量；候选值缺失或不一致时显示“待确认”。优先使用本地分子式、结构及已缓存分子量，缺失时才补查 PubChem。人工确认的结构保持优先，其余报告内容仍可打印。
- 报告展示准备时的库存快照。报告内的填写仅用于当前打印页，不会修改系统库存或保存为实验记录。

## 搜索语法

库存页支持两类组合输入：

- `CAS1&&CAS2&&CAS3`：匹配任意一个指定 CAS，适合实验步骤解析结果。
- `关键词1 关键词2`：使用半角空格分隔，要求多个词命中同一业务字段，最多 8 个词。

`&&` 查询仅用于 CAS 字段，批量 CAS 查询前后端上限均为 20000 字符，普通搜索输入最多 1000 个字符。实验步骤解析最多 50 个物料、每个最多 5 个候选 CAS，去重前最多 250 个合法 CAS，生成的查询串最长约 3498 字符，不会触及批量查询上限。

## 使用限制

- 解析结果仅用于辅助检索，需要结合实验原文和物料标签核对。
- LLM 未启用、接口地址缺失、API Key 缺失或模型名称缺失时，系统会返回对应配置提示。
- 实验步骤解析、CAS 匹配和报告导出按用户分别限流，默认 5 分钟内各 5 次。
- 单次 CAS 解析最多处理 50 个试剂，每个试剂最多保留 5 个 CAS 候选。
- 外部服务超时、限流或返回格式异常时，可缩短实验步骤后重试。
- 查询流程的前端没有整体超时；默认 LLM 网络超时为每次 30 秒，响应格式异常可重试 1 次；PubChem 网络超时为每次 20 秒，超时或特定服务错误最多重试 3 次。多试剂和多轮外部请求可能使整轮查询超过这些单次时间。
- 仓库自带 Docker/Nginx 配置未覆盖代理读取超时，沿用 [Nginx 默认的 60 秒](https://nginx.org/en/docs/http/ngx_http_proxy_module.html#proxy_read_timeout)：上游连续 60 秒没有返回数据时，代理会断开该请求；其他部署方式以实际反向代理配置为准。

## 隐私与用量记录

实验步骤会发送到已配置的 OpenAI 兼容服务。部署人员需要根据实验室的数据管理要求选择服务商并配置访问凭据。

后端仅记录调用用户、功能标识、服务类型、模型、尝试次数和 token 用量，不保存提示词或 LLM 响应正文。解析重试会按每次服务响应分别记录用量。
