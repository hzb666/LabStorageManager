# 快速上手

本页面向首次登录系统的使用者，也适合作为新成员的简要培训材料。目标不是覆盖全部功能，而是帮助读者在最短时间内完成首次登录、查看首页、理解公告入口并掌握主要业务菜单。

## 先确认账号类型

系统内常见账号分为三类：

- 管理员：负责审批、维护用户与公告。
- 普通用户：负责创建订单、查询库存、借还物品和管理个人设备。
- 公用账户：适用于公共终端或共享场景，可查库存、看公告和登记借用，但不能创建订单。

若登录后未看到“创建订单”按钮，应首先确认当前是否使用公用账户。

## 第一次登录

### 标准登录

首次在当前设备上使用系统时，通常进入标准登录页，需要输入以下信息：

- 用户名
- 密码

登录成功后，系统会进入首页仪表盘，并将当前设备记录到设备会话列表中，便于后续在个人账户页面查看。

### 锁屏式登录

若当前设备此前已登录过同一用户，系统可能进入更快捷的锁屏式登录界面：

- 页面显示上次登录用户的头像、姓名或用户名。
- 仅需输入密码即可重新进入系统。
- 需要更换使用者时，可通过“切换用户”返回标准登录模式。

该模式适合个人设备；在共享终端场景下，应特别注意切换用户，避免误用他人登录身份。

### 常见登录提示

- 用户名或密码错误：重新核对输入内容。
- 登录状态已失效，请重新登录：此前会话已过期或被清理。
- Redis 服务未连接：通常不影响继续登录，但部分依赖会话状态的体验可能退化。

## 登录后优先查看的区域

建议在进入业务页面前，先用约一分钟熟悉首页布局。

### 第一步：查看顶部区域

顶部区域通常包含以下高频入口：

- 置顶公告横幅：桌面端用于展示重要通知。
- 公告铃铛按钮：用于打开公告列表并显示未读数量。
- 主题切换与菜单按钮：在移动端尤其常用。

当铃铛按钮显示未读数时，建议优先阅读公告，尤其是采购规则、库存盘点、危险品管理和节假日安排等可能直接影响后续操作的通知。

### 第二步：查看左侧菜单

桌面端登录后，左侧通常显示主要导航菜单，常见包括：

- 仪表盘
- 试剂订单
- 耗材订单
- 库存列表
- 常用货架
- 导入数据
- 侧边栏底部的个人账户入口

管理员还会额外看到：

- 用户管理
- 公告管理

### 第三步：从仪表盘开始

首页默认页为仪表盘。该页面更接近个人工作台，重点展示当前待处理事项，而非全站统计。

## 先认识仪表盘

仪表盘会集中显示个人订单、借用记录和待入库事项，是首次使用时最适合观察系统工作方式的页面。

普通用户和管理员通常可看到以下四类入口：

- 试剂订单
- 耗材订单
- 当前借用
- 待入库

公用账户的仪表盘则更精简，主要保留借用相关内容。

如需进一步理解首页结构，可继续阅读 [仪表盘](/user-guide/dashboard)。

## 推荐的首次操作顺序

首次登录后，建议按以下顺序完成一次完整浏览：

1. 打开公告列表，确认近期是否存在重要通知。
2. 回到仪表盘，查看当前是否存在借用或待入库事项。
3. 打开库存列表，尝试搜索一项熟悉的试剂。
4. 打开常用货架，了解实验室常备物品的组织方式。
5. 根据实际职责，再进入试剂订单或耗材订单页面。

该顺序有助于先建立“系统中已有资源”的认识，再进入新建订单流程。

## 先掌握搜索与筛选

新用户常见问题并非不会点击按钮，而是未先确认系统中是否已有现货。先检索库存能够有效减少重复申购。

### 库存列表中的搜索方式

库存页搜索框主要适合以下关键词：

- 名称
- CAS 号
- 位置

查找试剂时，优先建议使用 CAS 号；仅掌握中文名称时，也可先按名称搜索，再通过展开详情确认目标条目。

### 常用货架中的搜索方式

常用货架支持更丰富的搜索字段，常见包括：

- 名称
- 别名
- CAS 号
- 品牌
- 分类
- 位置

该页面适合检索共享试剂、常备试剂及高频使用物品。

### 仪表盘中的快速搜索

仪表盘各标签页通常也带有搜索框。例如：

- 我的试剂订单可按名称、CAS 号、品牌和订购时间搜索。
- 我的耗材订单可按名称、规格和订购时间搜索。
- 我的借用记录可按名称和 CAS 号搜索。
- 待入库列表可按名称和 CAS 号搜索。

仅需查找个人当前记录时，优先在仪表盘内搜索通常更高效。

## 三个典型起步场景

### 场景一：申请一瓶试剂

建议按以下步骤处理：

1. 先在库存管理和常用货架中搜索名称或 CAS 号。
2. 确认无现货或现货不足后，进入“试剂订购”。
3. 创建订单时尽量完整填写名称、CAS 号、规格与用途。
4. 提交后等待审批。
5. 审批通过且物品送达后，在仪表盘中确认到货。
6. 如需补录位置，再通过“待入库”完成正式入库。

系统在试剂建单时会基于 CAS 号进行重复提醒，用于辅助核对系统内是否已有相关记录。

### 场景二：申请一批耗材

建议按以下步骤处理：

1. 先确认该物品确属耗材，而非需要库存追踪的试剂。
2. 进入“耗材订购”。
3. 填写名称、规格、数量及相关说明。
4. 提交后等待管理员审批。
5. 物品到货后，在仪表盘或耗材订单页确认收货并完成流程。

一次性材料或低值易耗品通常优先使用耗材流程。

### 场景三：借用现有库存

建议按以下步骤处理：

1. 进入库存管理，按名称或 CAS 号搜索目标物品。
2. 核对规格、剩余量与位置。
3. 点击“借用”。
4. 实验结束后，在仪表盘“当前借用”中完成归还。

公用账户在借用时必须指定真实借用人，用于保证后续追踪准确。

## 公告的使用方式

系统中公告主要通过两种方式展示：

- 顶部铃铛按钮：查看完整公告列表和未读数量。
- 顶部横幅：展示置顶且可见的重要公告。

可将铃铛理解为公告列表入口，将顶部横幅理解为当前优先级较高的提醒。

建议形成以下使用习惯：

- 当铃铛显示未读数量时，优先查看新增公告。
- 对可能影响业务流程的公告，进入详情页阅读全文，而非仅查看标题。
- 对暂时无需查看的顶部横幅，可先关闭；关闭并非永久生效，后续可能再次出现。

## 为什么应尽早了解个人账户页

个人账户页不仅用于修改头像或名称，更承担设备会话管理职责。该页面支持：

- 查看当前和历史登录设备
- 搜索设备名称或 IP
- 重命名设备
- 刷新会话
- 踢出其他设备

在办公室电脑、实验室终端与个人笔记本之间切换较频繁时，该页面尤为重要。共享终端使用结束后，也建议及时检查会话状态。

## 建议尽快建立的使用习惯

### 1. 先查库存，再决定是否下单

库存列表和常用货架均属于高频入口，其目的之一是减少重复采购。

### 2. 试剂到货后继续完成后续处理

试剂流程中的常见停滞点不是审批，而是物品已到但未继续完成到货确认或补录位置。

### 3. 借用后及时归还

仪表盘中的“当前借用”用于集中处理归还。及时归还有助于保证剩余量和责任记录准确。

### 4. 共享电脑上及时切换用户

系统支持记住上次登录用户，该能力适合个人设备，但在公用设备上存在误用风险。

### 5. 看不到按钮时先判断角色差异

常见情况包括：

- 未看到“创建订单”，通常与公用账户有关。
- 未看到“用户管理”“公告管理”，通常与管理员权限有关。
- 仪表盘卡片数量较少，通常由角色裁剪导致，而非页面故障。

## 常见概念区分

### “到货”与“入库”不是同一操作

试剂到货仅表示物品送达；入库则表示已补录位置并进入可管理库存。

### “常用货架”不等于“全部库存”

常用货架更适合查看高频、公用或常备试剂，完整库存仍需通过库存列表查询。

### “订单结束”不等于“进入库存”

耗材订单通常以采购完成为终点，不会自动转化为库存列表中的一条库存记录。
