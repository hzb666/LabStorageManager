# 更新日志

本页按版本概括项目的主要演进，用于帮助开发者快速判断能力边界、理解历史改动背景，并辅助阅读不同阶段的代码与文档。

## 0.5.0

- 首次发布 LabStorageManager，提供试剂、耗材、库存、借用、常用货架和订单流程的一体化管理能力。
- 完成 `FastAPI + SQLModel + SQLite(WAL)` 后端、`React + Vite` 前端、CLI/MCP、企业微信机器人和微信客服入口的整体集成。
- 库存模块支持新增、编辑、删除、借用、归还、导出、拼音搜索、字段搜索、模糊搜索和结构式搜索。
- 借用流程支持公用账户代借、真实借用人选择、归还时补规格、零剩余“用完”删除和库存删除日志。
- 试剂订单支持创建、审批、驳回、确认到货和一键入库；耗材订单支持创建、审批、驳回和确认收货。
- 常用货架采用“分组 + 瓶级条目”模型，支持 CAS 主数据、位置建议、加瓶、扣减和分组合并确认。
- 仪表盘支持个人视图、成员看板、公用账户视图和管理员管理视图，并展示审批、到货、收货和借用超时提醒。
- 新增用户、设备会话、公告、操作日志、日志归档、运行时缓存版本和 Docker Compose 部署能力。
- 机器人识别到 CAS 号时优先执行系统内精确查询；低库存阈值统一为 10%。
- 启动时检查常用货架瓶子和分组记录一致性，缺失分组时阻止启动并提示执行 backfill 脚本。

## 0.4.0

- 引入 CLI、MCP、企业微信机器人和微信客服能力，外部消息入口统一回到后端 API。
- CLI 增加库存、常用货架和 CAS 主数据查询能力，MCP 按白名单映射 CLI 命令，不直接访问数据库。
- 浏览器插件的配置改为构建期产物，采购清单可以进入购物车导入流程。
- 日志归档调度支持按服务器本地时间每天或每周执行，归档锁避免多 worker 重复运行。
- 生产上传请求上限对齐为 12MB，公告图片和头像仍保持 5MB 业务限制。

## 0.3.0

- 引入 SSE 实时推送、FTS 全文搜索、XLSX 导出和购物车批量导入。
- 抽象 `FilterTable`、高亮文本、通用操作按钮和表格状态管理，列表页交互收敛到统一模式。
- 上线常用货架管理和 CAS 主数据维护，支持按 `CAS + 品牌 + 规格` 形成稳定分组。
- 发布知识库站点并梳理 wiki 结构，项目文档形成统一入口和分层阅读路径。
- 增加结构式搜索、拼音检索和排序稳定性优化，库存检索体验进一步完善。

## 0.2.0

- 强化认证、会话和权限体系，补齐管理员日志、公用账户和设备管理能力。
- 上线公告系统、问题反馈入口、公告图片服务和头像相关能力。
- 完善试剂订单和耗材订单模型，补齐创建、编辑、审批、驳回、到货、收货和导出链路。
- 统一时间格式、错误消息表达、API 工具层和前端表单验证规则。
- 引入运行时缓存版本、路由懒加载、构建压缩和更稳定的前端状态同步。

## 0.1.0

- 搭建 `FastAPI + SQLModel + SQLite(WAL)` 后端骨架，并建立核心数据模型与基础 API。
- 接入 JWT 认证，替换硬编码用户逻辑，形成最小权限闭环。
- 落地 `React + Vite + TypeScript + Tailwind CSS` 前端基础框架。
- 完成库存、用户、手动入库、Excel 导入和基础列表页能力。
- 基于 `shadcn-admin` 风格重做前端主界面，补齐侧边栏、主题切换、响应式适配和通用 hooks。
