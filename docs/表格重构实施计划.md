# 库存列表表格重构实施计划

## 一、目标概述

将库存列表页面从原生 `<table>` 标签迁移到 TanStack Table + 虚拟滚动架构，实现：

- ✅ 状态全托管（展开行状态由 TanStack Table 管理）
- ✅ 虚拟滚动（支持海量数据渲染）
- ✅ 列宽拖拽 + 持久化
- ✅ **服务端排序**
- ✅ **服务端过滤（columnFilters）**
- ✅ 粘性表头（可选，支持粘性页眉）

#### 2.1.3 实现排序逻辑

```python
    # 在查询构建后、分页前添加排序
    if sort_field and hasattr(Inventory, sort_field):
        column = getattr(Inventory, sort_field)
        if sort_order == "desc":
            base = base.order_by(column.desc())
        else:
            base = base.order_by(column.asc())
    else:
        # 默认排序
        base = base.order_by(Inventory.created_at.desc())
```

#### 2.1.4 实现过滤逻辑

```python
    # 解析 filters 参数（格式：cas_number:64-17-5,status:available）
    if filters:
        for filter_item in filters.split(','):
            if ':' in filter_item:
                field, value = filter_item.split(':', 1)
                if hasattr(Inventory, field):
                    column = getattr(Inventory, field)
                    # 字符串字段使用模糊匹配
                    if isinstance(value, str):
                        base = base.where(column.ilike(f"%{value}%"))
                    else:
                        base = base.where(column == value)
```

#### 2.1.5 缓存 key 更新

```python
    # 缓存 key 需包含排序和过滤参数
```

```tsx
const loadInventory = useCallback(async () => {
  const params: any = {
    skip: (page - 1) * pageSize,
    limit: pageSize,
  }

  // 添加搜索参数
  if (searchQuery) {
    params.search = searchQuery
    params.fuzzy = fuzzySearch
  }

  // 添加排序参数
  if (sorting.length > 0) {
    params.sort_field = sorting[0].id
    params.sort_order = sorting[0].desc ? 'desc' : 'asc'
  }

  // 添加过滤参数（服务端）
  if (columnFilters.length > 0) {
    const filters = columnFilters
      .filter(f => f.value)
      .map(f => `${f.id}:${f.value}`)
      .join(',')
    if (filters) {
      params.filters = filters
    }
  }

  const response = await inventoryAPI.list(params)
  // ...
}, [page, pageSize, searchQuery, fuzzySearch, sorting, columnFilters])
```
