### 讨论 1: 库存页面优化 (2026-02-19)

#### 需求 1: 库存编辑功能
- [ ] 库存列表增加"编辑"按钮
- [ ] 点击后弹出窗口编辑库存信息
- [ ] 编辑字段：中文名(name)、英文名(english_name)、分类(category)、库存位置(location)、CAS号(cas_number)、剩余量(remaining_quantity)、品牌(brand)、状态(status)、备注(notes)
- [ ] 入库时间(created_at)只读显示
- [ ] 该功能需设计为可复用的编辑弹窗组件（将来用于试剂/耗材订单列表）

#### 需求 2: 库存列表列调整
- [ ] 调整列顺序为：中文名、库存位置、CAS号、剩余量/规格、品牌、入库时间、状态、备注
- [ ] "剩余量/规格"融合为一列显示（格式："200/500 ml"，即 remaining/initial + unit）
- [ ] 库存状态：在库(in_stock)、借用(borrowed)、用完(consumed)

#### 需求 3: 分页增强
- [ ] 增加"跳转到第几页"功能
- [ ] 用户可直接输入页码跳转到指定页

#### 需求 4: 搜索优化
- [ ] 搜索时在表内高亮匹配的字段
- [ ] 数量计数显示搜索结果数而非总数

#### 技术注意事项
- 后端 InventoryUpdate DTO 需扩展支持 name、cas_number 更新
