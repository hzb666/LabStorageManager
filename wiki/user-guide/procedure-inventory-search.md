# 实验步骤查库存

实验步骤查库存用于从实验记录中识别试剂名称，解析 CAS 号，并在库存页集中查看可用情况。该功能提供辅助检索结果，原始实验步骤和实际库存记录仍是核对依据。

## 使用条件

- 管理员和普通用户可以使用。
- 公用账户不显示该入口。
- 后端需要启用并配置 OpenAI 兼容 LLM 接口。
- 单次输入最多 5000 个字符。

## 操作流程

1. 打开库存管理页，点击 **实验步骤查库存**。
2. 粘贴实验步骤并提交解析。
3. 系统先提取非通用试剂名称，再通过 PubChem 解析 CAS 候选。
4. 解析完成后进入库存页，CAS 查询条件会以 `&&` 连接。
5. 在解析面板中核对原文高亮、CAS 候选和库存命中情况。

解析过程分为实验步骤识别、PubChem 解析和库存查询三个阶段。页面会保留本次结果 10 分钟，并限定在当前登录用户和当前浏览器会话内。

## 结果状态

| 状态 | 含义 | 处理方式 |
| --- | --- | --- |
| 已识别 CAS | 试剂名称已解析出 CAS | 核对候选 CAS 和库存命中项 |
| 库存未命中 | CAS 已识别，库存中未找到对应记录 | 核对 CAS 后决定采购或补录 |
| 未识别 CAS | 试剂名称未得到可用 CAS | 参考候选信息并手动搜索名称 |
| 常用不查 | 常见溶剂、气体等通用物料 | 按实验室常规渠道确认 |
| 通类不查 | 名称仅表示一类试剂 | 补充具体化合物名称后重新查询 |

当一个名称对应多个 CAS 时，面板会展示候选列表。库存查询会带入有限数量的候选 CAS，使用者需要结合实验上下文确认目标化合物。

## 搜索语法

库存页支持两类组合输入：

- `CAS1&&CAS2&&CAS3`：匹配任意一个指定 CAS，适合实验步骤解析结果。
- `关键词1 关键词2`：使用半角空格分隔，要求多个词命中同一业务字段，最多 8 个词。

`&&` 查询仅用于 CAS 字段，页面允许较长的批量 CAS 输入。普通搜索输入最多 1000 个字符。

## 使用限制

- 解析结果仅用于辅助检索，需要结合实验原文和物料标签核对。
- LLM 未启用、接口地址缺失、API Key 缺失或模型名称缺失时，系统会返回对应配置提示。
- 解析和 CAS 解析均按用户限流，默认 5 分钟内各 10 次。
- 单次 CAS 解析最多处理 50 个试剂，每个试剂最多保留 5 个 CAS 候选。
- 外部服务超时、限流或返回格式异常时，可缩短实验步骤后重试。

## 隐私与用量记录

实验步骤会发送到已配置的 OpenAI 兼容服务。部署人员需要根据实验室的数据管理要求选择服务商并配置访问凭据。

后端仅记录调用用户、功能标识、服务类型、模型、尝试次数和 token 用量，不保存提示词或 LLM 响应正文。解析重试会按每次服务响应分别记录用量。
