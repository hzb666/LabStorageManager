# 使用者指南总览

本组文档面向实验室库存管理系统的日常使用者，重点说明系统中的核心对象、主要页面与常见使用路径，帮助读者在不涉及技术实现细节的前提下完成采购、入库、借还、公告查看与账户管理等工作。

## 系统定位

LabStorageManager 并非单一的库存登记工具，而是一套覆盖实验室日常业务全流程的协同平台。系统将申购、审批、到货、入库、库存查询、借用归还、公告提醒与设备会话管理整合到同一工作界面中，适合多人协作和后续追溯。

从使用视角看，系统可以概括为三个层次：

- 订单层：记录采购申请及其审批流转。
- 库存层：记录已进入实验室的实物库存。
- 个人工作层：汇总待处理事项，如待入库、当前借用和未读公告。

## 适用角色

系统主要服务以下三类使用者：

- 管理员：负责审批订单、维护用户、管理公告及处理部分导入工作。
- 普通用户：负责日常申购、库存查询、借用归还及个人账户管理。
- 公用账户使用者：适用于公共终端或共享查询场景，主要用于查库存、看公告和登记借用，不承担订单创建职责。

建议阅读路径如下：

- 偶发查询库存或首次接触系统时，先阅读 [快速上手](/user-guide/quick-start)。
- 需要理解角色差异和页面入口时，继续阅读 [角色与导航](/user-guide/roles-and-navigation)。

## 系统支持的核心工作

系统目前覆盖以下高频场景：

- 提交试剂订单，并跟踪待审批、已批准、已到货与已入库状态。
- 提交耗材订单，并在收货后完成采购闭环。
- 在库存列表中按名称、CAS 号、位置等条件检索现有物品。
- 在库存中发起借用，并在实验结束后按使用量或剩余量归还。
- 在常用货架中集中查看共享或常备试剂，减少重复申购。
- 在仪表盘中集中查看个人订单、当前借用和待入库事项。
- 通过公告入口查看未读公告，并在桌面端接收置顶公告横幅提醒。
- 在个人账户页面中查看设备会话、刷新会话、重命名设备和清理旧设备。

## 三个核心对象

虽然系统包含多个页面，但大多数业务均围绕以下三个对象展开。

### 1. 试剂订单

试剂订单用于申请采购需要后续追踪的物品，通常包含 CAS 号、规格、品牌、用途等字段。订单经过审批后，可继续处理到货确认与正式入库。

试剂订单对应的业务含义是：某项试剂需要完成从申购到到货、再到库存落位的完整跟踪。

### 2. 耗材订单

耗材订单适用于一次性耗材、低值易耗品或无需瓶级库存追踪的物品。其重点在于采购完成，而非后续库存管理。

耗材订单对应的业务含义是：完成一项采购申请，并确认该批耗材已经收齐或采购完成。

### 3. 库存记录

库存记录表示物品已经进入系统库存，可被检索、借用、归还和查看详情。记录通常包含名称、CAS 号、规格、剩余量、位置、危险标记与借用状态等信息。

从业务角度看，库存记录用于回答“实验室当前实际有哪些物品”。

## 三者关系

典型业务流程如下：

1. 先确认实验室内是否已有现货。
2. 如无现货，再创建试剂订单或耗材订单。
3. 试剂订单审批后，可继续确认到货并完成入库。
4. 耗材订单审批后，通常以确认收货作为流程结束。
5. 已正式入库的物品进入库存视图，供后续查询、借用和归还。

这也是订单页面与库存页面并存且相互独立的原因。

## 核心能力一览

从使用侧可感知的能力看，系统主要包括：

- 采购与审批：试剂、耗材分开建单，状态清晰，支持管理员审批。
- 到货与入库：试剂支持确认到货，也支持直接一键入库或稍后补录位置。
- 库存查询与借还：库存列表与仪表盘可协同完成查询、借用与归还。
- 共享试剂管理：常用货架用于集中展示公用或高频使用试剂。
- 站内通知：公告按钮显示未读数，置顶公告可通过顶部横幅展示。
- 账户安全：个人账户页面用于管理设备会话和处理登录安全相关操作。

## 常见页面

系统的主要业务入口集中在以下页面：

| 页面 | 路由入口 | 主要用途 |
| --- | --- | --- |
| 仪表盘 | `/` | 查看个人订单、当前借用与待入库事项 |
| 试剂订购 | `/reagents` | 创建、查看、搜索试剂订单；管理员可审批和导出 |
| 耗材订购 | `/consumables` | 创建、查看、搜索耗材订单；管理员可审批和导出 |
| 库存管理 | `/inventory` | 搜索库存、查看位置、借用、编辑、手动入库 |
| 常用货架 | `/common-shelf` | 查看共享试剂和常备试剂 |
| 导入数据 | `/import` | 使用模板批量导入或补录库存 |
| 个人账户 | `/devices` | 管理个人资料、设备会话与安全操作 |
| 用户管理 | `/admin/users` | 管理员维护账号、启停用户、查看用户信息 |
| 公告管理 | `/admin/announcements` | 管理员发布、编辑、置顶和隐藏公告 |
| 用户操作日志 | `/admin/logs` | 管理员查看关键操作记录 |

## 页面速查表

以下速查表用于快速判断应进入的页面：

| 使用目的 | 推荐页面 | 说明 |
| --- | --- | --- |
| 查看当日待处理事项 | 仪表盘 | 集中展示个人订单、借用和待入库事项 |
| 申请采购试剂 | 先库存管理/常用货架，再试剂订购 | 先确认无现货，再发起采购申请 |
| 申请采购耗材 | 耗材订购 | 耗材具有独立流程，不应混入试剂流程 |
| 查找现有试剂 | 库存管理 | 支持按名称、CAS 号和位置搜索 |
| 查看共享试剂 | 常用货架 | 适合查看公用或高频使用物品 |
| 完成归还 | 仪表盘的“当前借用” | 待归还记录最集中 |
| 补录位置完成入库 | 仪表盘的“待入库” | 处理已到货但尚未正式落位的试剂 |
| 查看站内通知 | 顶部公告按钮 | 公告列表与未读数均在此展示 |
| 清理旧设备会话 | 个人账户 | 可重命名、刷新或踢出其他设备 |

## 使用要点

- 未登录访问业务页面时，系统会跳转回登录页。
- 管理员菜单单独展示，普通用户不会看到“用户管理”“公告管理”“用户操作日志”等入口。
- 公用账户不能创建订单，因此在试剂订购和耗材订购页不会显示“创建订单”按钮。
- 公用账户可以在库存页登记借用，但必须选择真实借用人。
- 仪表盘内容会根据角色裁剪，公用账户仅保留借用相关视图。
- 公告既可以通过铃铛按钮查看，也可能以置顶横幅方式展示。

## 建议建立的使用模型

对于首次接触系统的使用者，建议优先建立以下顺序感：

- 先确认是否已有现货。
- 再决定是否需要采购。
- 到货后继续完成后续处理。
- 借出的物品应及时归还。
- 无法快速判断时，先回到仪表盘查看待处理事项。

建立以上使用顺序后，大多数页面的功能边界会更容易理解。
